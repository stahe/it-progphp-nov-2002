# Introduzione alla programmazione web in PHP4

🔗 Corso originale:
[https://stahe.github.io/it-progphp-nov-2002/](https://stahe.github.io/it-progphp-nov-2002/)

## Panoramica

Questo repository contiene **materiali didattici dedicati alla programmazione web con PHP4**.
Si tratta di un documento didattico progettato per supportare l'insegnamento e non costituisce un corso esaustivo.

Il documento permette agli studenti di scoprire le basi della programmazione web in PHP e fornisce una risorsa per i loro esercizi e sperimentazioni.

## Origine del documento

Questo materiale deriva direttamente dal corso **“Introduzione alla programmazione web in Java”**.
La struttura didattica è stata mantenuta, ma gli esempi e le soluzioni sono stati **adattati a PHP**.

Pertanto, per un lettore che ha familiarità con **Java e PHP**, diventa possibile confrontare:

* una soluzione Java
* una soluzione PHP

per **lo stesso problema di programmazione web**.

## Obiettivi di apprendimento

Questa risorsa mira a:
* Introdurre le basi della programmazione web lato server
* Presentare esempi concreti di codice PHP
* Fungere da base operativa per gli studenti
* Consentire un confronto didattico tra Java e PHP

## Note

* Questo documento è **materiale didattico**, non un manuale completo.
* Alcuni argomenti **non sono trattati o sono solo brevemente introdotti**.
* **L'approfondimento richiede la guida di un istruttore**.

Ciononostante, le informazioni presentate consentono agli studenti di **lavorare in modo indipendente** nella maggior parte dei casi. 

## Destinatari:

Questo documento è destinato principalmente a:
* **studenti alle prime armi con la programmazione web**
* persone che desiderano **confrontare gli approcci Java e PHP**
* studenti che utilizzano PHP in ambito didattico
